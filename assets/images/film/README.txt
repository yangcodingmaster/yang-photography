Film（胶卷档案）图片文件夹
================================

命名规则：
  · 每卷一个文件夹，文件夹名 = data.js 里这卷的 id（连字符，不要空格）
    命名约定：年月-型号-格式，例如 2403-gold200-120、2512-portra400-135、2605-fujifilm-135
    （年月 = 拍摄年月，如 2403 = 2024 年 3 月；格式 = 135 或 120）
  · 文件夹里的照片按这卷的拍摄顺序命名：01.jpeg、02.jpeg、03.jpeg…（零填充两位）
  · 相机直出的 HEIC、扫描出的 BMP 都必须先转成真 JPEG（长边 2560 / 质量 90），规则同全站

加新一卷：
  1. 按上面规则建文件夹、放照片
  2. 打开 data.js 拉到最底下的 allFilms，照抄任意一卷加一段：
     id / stock / label / format / camera / lens / date / title / desc / photos
  3. title（作品名）/ desc（一句解释）/ lens（镜头）都可留空，留空会自动隐藏
  ⚠️ 新型号（SHELL_STYLES 里没有的）要在 film.html 的 SHELL_STYLES 补一行品牌配色，
     否则那卷的筒身会显示成灰调回退
