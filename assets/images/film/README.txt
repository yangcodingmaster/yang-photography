Film（胶卷档案）图片文件夹
================================

命名规则：
  · 每卷一个文件夹，文件夹名 = data.js 里这卷的 id（连字符，不要空格）
    命名习惯：型号缩写-序号，例如 portra400-01、gold200-02
  · 文件夹里的照片按这卷的拍摄顺序命名：01.jpeg、02.jpeg、03.jpeg…
  · 相机直出的 HEIC 必须先转成真 JPEG（长边 2560 / 质量 90），规则同全站

填好照片后：
  打开 data.js 拉到最底下的 allFilms，把对应卷的 src 从
  'assets/images/archive/...'（测试用的临时图）换成
  'assets/images/film/文件夹名/01.jpeg' 这样的真实路径，
  并把 stock / format / camera 改成这卷的真实信息。

当前的文件夹是按测试数据预建的，可以自由改名/增删——
只要保证文件夹名和 data.js 里的 id 一致就行。
